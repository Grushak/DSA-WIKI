# Trollkopf
Ein markanter Felsen in der Nähe von [[Neu Wurzeln]].

- **Phänomene:** Der Felsen nimmt Energie aus der Umgebung auf. Um den Felsen entstehen Mindergeister.
- **Ereignisse:** Auf dem Felsen stand eine vom Blitz getroffene Esche, die von [[Pjerow von Jelinske]] untersucht wurde. Die Helden pflanzten später eine junge Esche an derselben Stelle.
